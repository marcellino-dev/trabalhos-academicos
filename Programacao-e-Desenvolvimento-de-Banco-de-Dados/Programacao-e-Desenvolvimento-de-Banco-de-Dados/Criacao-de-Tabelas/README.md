# Criação de Tabelas (MySQL)

Disciplina: Programação e Desenvolvimento de Banco de Dados
Unidade: U1 - Estrutura de um Repositório de Dados
Aula: A1 - Criação de Tabelas

Script SQL que cria o banco `empresa` e a tabela `funcionarios` e realiza consultas com:

- SELECT, FROM e WHERE
- UPPER e alias com AS
- SUM, GROUP BY e ORDER BY
- LIKE

## Como executar

Pelo terminal, com o MySQL instalado:

```bash
mysql -u root -p < funcionarios.sql
```

Ou copie o conteúdo de `funcionarios.sql` para o myCompiler (https://www.mycompiler.io/pt/new/mysql) ou para uma aba de consulta do MySQL Workbench e execute.

## Arquivos

| Arquivo | Conteúdo |
|---|---|
| `funcionarios.sql` | criação do banco, da tabela, inserção dos dados e consultas |
| `Criacao_de_Tabelas_Funcionarios.pdf` | relatório da aula prática |

## Tecnologias

- SQL
- MySQL
