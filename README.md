## Projetos

### Construtores_e_Sobrecarga

Disciplina: Linguagem Orientada a Objetos
Unidade: U2 - Estruturas do Desenvolvimento Orientado a Objetos
Aula: A1 - Construtores e Sobrecarga

Programa em Java que simula um cadastro de produtos, aplicando:

- Sobrecarga de construtores (construtor padrao e construtor com parametros)
- Atributo estatico compartilhado entre objetos
- Metodo estatico para contagem de instancias criadas

### Classes-Abstratas-e-Tratamento-de-Excecoes

Disciplina: Linguagem Orientada a Objetos
Unidade: U3 - Classes e Interfaces
Aula: A4 - Tratamento de Excecoes

Programa em Java que simula operacoes matematicas, aplicando:

- Classe abstrata com metodo abstrato
- Heranca e sobrescrita de metodos em subclasses
- Excecao personalizada
- Tratamento de erros com try-catch
